# Telegram AI-автоответчик для Вероники

Userbot, который отвечает за тебя в личных чатах Telegram через Claude
и пересылает важное в Saved Messages.

## ⚠️ Важно перед запуском

Автоматизация личного аккаунта — серая зона в правилах Telegram.
Чтобы снизить риск блокировки:
- Заполни BLACKLIST_IDS (директор, близкие) — с ними не переписывайся ботом
- Не отвечай в групповых чатах (уже отключено в коде)
- Не убирай задержки перед ответом
- Проверяй логи первую неделю

## Шаг 1. Получить Telegram API-ключи

1. Открой https://my.telegram.org
2. Войди по номеру телефона
3. **API development tools** → создай приложение (название любое)
4. Скопируй `api_id` и `api_hash`

## Шаг 2. Получить Claude API-ключ

1. https://console.anthropic.com → Settings → API Keys → Create Key
2. Скопируй ключ (`sk-ant-...`)
3. Пополни баланс минимум на $5

## Шаг 3. Первый запуск (локально)

```bash
python -m venv venv
source venv/bin/activate       # Windows: venv\Scripts\activate
pip install -r requirements.txt
cp .env.example .env
# впиши свои ключи в .env
python main.py
```

При первом запуске Telegram попросит:
1. Номер телефона
2. Код из SMS
3. Пароль двухфакторки (если включена)

После авторизации создастся файл `veronika.session` — это ключ доступа
к твоему аккаунту. **Никому не показывай.**

## Шаг 4. Настроить config.py

Впиши ID людей в `BLACKLIST_IDS` и `VIP_IDS`.
Как узнать ID: перешли сообщение человека боту @userinfobot.

Отредактируй `KEYWORDS` под свои триггеры.

## Шаг 5. Деплой на Railway

1. Залей проект в приватный GitHub-репозиторий
2. **Обязательно** добавь в `.gitignore`: `.env`, `*.session`, `venv/`
3. Загрузи `veronika.session` через Railway UI (Volumes) — иначе
   при деплое Telegram запросит код заново, а SMS уйдёт на телефон
4. Пропиши переменные окружения из `.env` в Railway
5. Стартовая команда: `python main.py`

Могу помочь с деплоем на Railway — у меня есть доступ к твоему workspace.

## Управление ботом

Пиши команды **в чат с самой собой** (Saved Messages):

- `/pause` — выключить автоответы на 1 час
- `/pause 6h` — на 6 часов
- `/pause 30m` — на 30 минут
- `/resume` — включить обратно
- `/status` — узнать текущий статус

## Что делать, если бот отвечает плохо

Правь `SYSTEM_PROMPT` в `config.py`. Добавь примеры хороших/плохих
ответов, уточни стиль. После правки — рестарт.
